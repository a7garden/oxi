## 요구사항

https://github.com/xai-org/grok-build.git 의 TUI 레이아웃을 코드로 분석해서, oxicode-tui의 레이아웃을 그와 동일한 구조로 리디자인하라.

시각적으로 참고할 수 없으니 반드시 grok-build 저장소의 소스 코드를 직접 읽고 레이아웃을 파악한 후 적용할 것.

## 현재 oxicode-tui 상태

- **프레임워크:** ratatui 0.30 + crossterm 0.29
- **렌더링:** TapeEngine (native scrollback) + ratatui overlays
- **레이아웃:** `Container` + `Component` trait 기반 vertical stack
- **컴포넌트:** ChatView (메인), DashboardWidget, Input, Footer, CompletionPopup, TranscriptRenderer
- **특징:** 순수 vertical stack, 가로 분할 없음

## grok-build 레이아웃 (참고 대상)

- **프레임워크:** ratatui v0.28+ + crossterm
- **저장소:** https://github.com/xai-org/grok-build.git → `crates/codegen/xai-grok-pager/`
- **핵심 파일:**
  - `src/views/agent.rs` — `AgentViewLayout` 구조체, `compute()` 메서드, `ActivePane` enum (Scrollback, Todo, Queue, Prompt, Tasks, Catalog), `PaneAreas`
  - `src/app/agent_view/render.rs` — `AgentView::draw()` 렌더 파이프라인 (status bar → optional panes → scrollback → prompt → shortcuts bar)
  - `src/app/agent_view/mod.rs` — AgentView 상태 + input 핸들링
  - `src/app/agent_view/panes.rs` — Pane input 핸들링
  - `src/views/status_bar.rs` — 1-row status bar (left/center/right)
  - `src/views/shortcuts_bar.rs` — 하단 키보드 단축키 바
  - `src/views/welcome/mod.rs` — Welcome 화면 레이아웃
  - `src/views/tasks_pane.rs` — Tasks pane (bg tasks + subagents)
  - `src/views/dashboard/` — Agent dashboard
  - `src/app/app_view.rs` — AppView root (Welcome/Agent/Dashboard)

- **레이아웃 구조 (위→아래):**
  1. **StatusBar** — 1줄, left/center/right 텍스트
  2. **Optional panes** (collapsible strips): Tasks, Todo, Queue, Catalog
  3. **Scrollback** — 메인 채팅 영역 (dominant, 중간)
  4. **Banner/CTA/Follow-ups** — 컨텍스트에 따라
  5. **Prompt** — 입력 영역
  6. **ShortcutsBar** — 키보드 단축키 힌트

- **ActivePane enum:** Scrollback, Todo, Queue, Prompt, Tasks, Catalog
- **PaneAreas:** 마우스 hit-testing용 영역 정보
- **Welcome 화면:** status bar + 중앙 정렬 로고 + 메뉴 + 프롬프트
