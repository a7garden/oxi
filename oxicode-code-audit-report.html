✗ F-3 높음 — 프로바이더 공유 HTTP 클라이언트에 타임아웃 부재

oxicode-ai/src/providers/mod.rs:65-68:

pub fn shared_client() -> &'static reqwest::Client {
    static CLIENT: OnceLock<reqwest::Client> = OnceLock::new();
    CLIENT.get_or_init(reqwest::Client::new)
}

모든 8개 프로바이더가 shared_client()를 사용. reqwest::Client::new()는 timeout 미설정. TCP 연결 성공 후 TLS handshake 또는 응답 청크 hang 시 영원히 대기. CLI의 동일 함수 (oxicode-cli/src/util/http_client.rs:14-22)는 올바르게 30s timeout 설정 — 두 클라이언트가 비대칭. panic = "abort" release 프로파일과 결합 시 사용자는 frozen CLI를 kill해야 함.

수정: Client::builder().connect_timeout(10s).timeout(600s).build().expect("...") — 스트리밍 응답을 위해 timeout은 길게(예: 10분) 잡되 connect_timeout은 짧게.

⚠ F-10 높음 — is_dangerous_command 경고만, 차단 안 함

oxicode-agent/src/tools/bash.rs:48-58 정의는 함수 docstring에 명시: "This does NOT block execution - it only emits a warning." 즉 | sh, /etc/passwd 접근, 기타 위험 패턴이 감지되어도 실행됨. build_shell_command(line 282-313)는 sh -c <command> 형태로 LLM의 입력을 그대로 셸에 전달.

수정: 최소한 | sh, | bash, /etc/passwd, /etc/shadow 패턴은 차단 모드로 승격 (현재는 warn만). 또는 dry-run 모드 추가.

⚠ Domain 3 관찰 — TUI 오버레이의 raw-pointer unsafe

✗ F-6 높음 — 매 토큰마다 AssistantMessage 전체 deep-clone (8 프로바이더)

도구 호출 한 턴이 user message + assistant text + tool result + assistant follow-up = 4 appends × (3 lock acquires + 1 file open syscall + 1 unbuffered write syscall) = 12 lock + 8 syscall. lock 순서는 line 1267-1271 주석에 명시되어 있어 deadlock은 없지만, contention이 동시 세션에서 발생.

수정: BufWriter<File>로 전환, File 핸들은 SessionManager 생성 시 1회 오픈. 3개 write lock을 단일 Mutex<AppendState>로 통합하거나, 인덱스 rebuild는 read-only 스냅샷 기반으로.

ℹ 결론

verdict: 수정 후 출시 (Ship with fixes). oxicode는 견고한 foundation과 명확한 아키텍처 의도를 가진 mature 프로젝트이지만, 두 개의 supply-chain 결함 (lockfile 무결성 write-only, 네이티브 확장 무결성 미검증)과 한 개의 reliability 결함 (프로바이더 클라이언트 타임아웃 부재)이 1.0 출시 전에 반드시 해결되어야 한다. F-1/F-2/F-3은 각각 ~0.5–2일 노력의 additive 수정으로 해결 가능하며 기존 API 호환을 깨지 않는다. P1/P2 결함은 모두 iterative 개선 대상이며 출시를 차단하지 않는다. CRITICAL 결함 해결 후 0.42.x로 버전 bump + CHANGELOG에 security advisory 게시를 권장.

방법론 (Methodology): 본 보고서는 2026-06-21에 HEAD e4bb5e42 ("Release v0.41.1")에서 작성됨. 9개 분석 도메인(Security, Architecture, Concurrency, Error handling, Performance, Testing, Supply chain, DX, Docs)을 explore subagent 병렬 실행으로 수행. 모든 결함은 메인 세션에서 citation audit으로 file:line 재검증 완료. 15/15 인용 verified, 0 struck. 모든 line number는 감사 시점 기준 — 이후 코드 변경 시 drift 가능.

범위 (Scope): Rust 2024 워크스페이스 6 crates, 401 .rs 파일, 177,164 LOC. MSRV 1.96. 패키지 매니저, 네이티브/WASM 확장, MCP, Bash tool, TUI, 공급망 포함. 감사 도중 oxicode-code-review-report.html (unstaged) 발견 — 무관.

읽기 전용: 본 감사는 읽기 전용으로 수행됨. 프로젝트 트리에 어떤 변경도 가하지 않음. 모든 도구는 read, search, bash(grep/count), find, lsp에 한정. cargo build/test/clippy/audit는 실행하지 않음.
